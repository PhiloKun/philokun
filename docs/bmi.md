# bmi — BMI 计算与健康建议

根据身高（厘米）与体重（千克）计算身体质量指数（BMI），并给出 WHO 成人标准分类与理想体重区间。纯计算，零云依赖。

## 用法

| 命令 | 作用 |
|------|------|
| `philokun bmi <身高cm> <体重kg>` | 计算 BMI 与分类 |
| `philokun bmi <身高cm> <体重kg> -u` | 同时显示理想体重区间 |

## 示例

```bash
philokun bmi 175 68
# 身高 175 cm，体重 68.0 kg
# BMI = 22.2
# 分类：正常

philokun bmi 175 68 -u
# 理想体重区间（18.5~24.9）：56.7 ~ 76.3 kg
```

## 分类标准（WHO 成人）

| BMI | 分类 |
|-----|------|
| < 18.5 | 偏瘦 |
| 18.5 ~ 24.9 | 正常 |
| 25.0 ~ 29.9 | 超重 |
| >= 30.0 | 肥胖 |

## 实现说明

- `BMI = 体重(kg) / 身高(m)²`，身高先换算成米。
- `-u` 时按 18.5 与 24.9 反推理想体重区间。
- 身高 / 体重必须为正数，否则报错。
