# now — 时间 / 时间戳转换

显示当前时间，或在 Unix 时间戳与日期字符串之间互转。零依赖，开发调试常用。

## 用法

```bash
philokun now                       # 当前本地时间 + 时间戳（秒/毫秒）
philokun now -u                    # 当前 UTC 时间
philokun now 1690000000            # 时间戳(秒) -> 日期
philokun now 1690000000000         # 时间戳(毫秒) -> 日期
philokun now 2023-07-22T12:00:00   # 日期 -> 时间戳
```

## 示例

```bash
$ philokun now -u
2023-07-22 04:26:40
时间戳: 1690000000
毫秒:   1690000000000

$ philokun now 1690000000
2023-07-22 12:26:40

$ philokun now 2023-07-22
时间戳: 1690003200
毫秒:   1690003200000
```

## 说明

- 无参数时同时打印本地时间、秒级与毫秒级时间戳。
- 时间戳 ≥13 位按毫秒解析，否则按秒解析。
- 支持的日期格式：`2006-01-02 15:04:05`、`...T...`、`2006-01-02 15:04`、`2006-01-02`、RFC3339。
- `-u` 切换到 UTC 时区（不影响时间戳数值，只影响日期展示）。
