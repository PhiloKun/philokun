# serve — 临时静态文件服务器

把当前目录（或指定目录）作为一个静态文件服务器跑起来，方便在局域网内临时分享文件，或本地预览网页。基于标准库 `net/http`。

## 用法

```bash
philokun serve                  # 服务当前目录，默认 0.0.0.0:8080
philokun serve ./dist -p 9000   # 服务指定目录与端口
philokun serve ./docs --host 127.0.0.1 -p 8000
```

## 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `[目录]` | 当前目录 `.` | 要服务的目录（必须存在且为目录） |
| `-p, --port` | 8080 | 监听端口 |
| `--host` | 0.0.0.0 | 监听地址（`0.0.0.0` 允许局域网访问，仅本机用 `127.0.0.1`） |

## 示例

```bash
$ philokun serve ./dist -p 9000
在 http://0.0.0.0:9000 提供 /abs/path/to/dist
（Ctrl+C 停止）
```

启动后浏览器打开对应地址即可浏览目录文件。适合：把打包后的前端 `dist/` 临时给别人看、本地预览生成的 HTML、在手机上访问电脑里的文件等。

> 提示：仅用于临时分享，不提供任何鉴权或限速；用完记得 `Ctrl+C` 关闭。
