# `calc` 表达式计算器

在终端里计算数学表达式，支持四则运算、括号、幂运算以及两个常用函数。仅用标准库，采用双栈（调度场 + 求值）算法，不引入任何第三方依赖。

## 用法

```bash
philokun calc "1 + 2 * 3"          # 7
philokun calc "(2+3)^2 / 5"        # 5
philokun calc "sqrt(16) + abs(-3)" # 7
```

## 支持的运算符与函数

| 符号 | 含义 |
|------|------|
| `+ - * /` | 加 减 乘 除 |
| `^` | 幂运算（整数指数） |
| `()` | 括号，改变优先级 |
| `sqrt(x)` | 平方根 |
| `abs(x)` | 绝对值 |

运算优先级遵循常规数学约定：`^` > `*` `/` > `+` `-`，括号最高。支持表达式开头与运算符后的一元负号（如 `-3 + 5`、`3 * (-2)`）。

整数结果直接以整数形式输出，含小数时以 `%.6g` 格式展示。

## 实现说明

| 层 | 文件 | 职责 |
|----|------|------|
| 命令 | `cmd/calc.go` | `tokenize` 分词 → 双栈求值 → 格式化输出 |

- `tokenize`：把表达式拆成数字 / 运算符 / 括号 / 函数名，并处理一元负号。
- 求值：维护操作数栈与运算符栈，按优先级出栈计算；函数名（sqrt/abs）在遇 `)` 时作为一元运算处理。
- `sqrt` 用牛顿迭代法实现，避免引入 `math` 包以保持轻量。
