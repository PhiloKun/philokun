# port — 端口占用检测

检测本地一个或多个 TCP 端口是否被占用，支持多端口与区间。零云依赖。

## 用法

| 命令 | 作用 |
|------|------|
| `philokun port <端口>` | 检测单个端口 |
| `philokun port <端口...>` | 同时检测多个端口 |
| `philokun port <a>-<b>` | 检测一段区间（如 `8080-8090`） |
| `philokun port -H <地址> <端口>` | 指定检测地址（默认 `127.0.0.1`） |

## 示例

```bash
philokun port 8080
# 端口 8080  → 空闲

philokun port 8080 9000 3000
# 端口 8080  → 空闲
# 端口 9000  → 已被占用

philokun port 8080-8082
# 端口 8080  → 空闲
# 端口 8081  → 已被占用
# 端口 8082  → 空闲

philokun port -H 0.0.0.0 5432
```

## 实现说明

- 通过 `net.Listen("tcp", addr)` 尝试占用端口来判断空闲/占用，检测后立即关闭。
- 任一端口被占用时命令以非零码退出，便于脚本判断。
- 端口范围 `1 ~ 65535`，非法值会报错。
