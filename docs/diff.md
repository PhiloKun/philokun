# diff — 行级文本差异

逐行比较两个文件，输出基于最长公共子序列（LCS）的增删标记。纯标准库实现。

## 用法

| 命令 | 作用 |
|------|------|
| `philokun diff <文件A> <文件B>` | 行级差异（含上下文行） |
| `philokun diff -u <文件A> <文件B>` | 紧凑模式：仅显示差异行 |

## 示例

```bash
philokun diff a.txt b.txt
#  a
# -b
# +x
#  c
#
# 摘要: 新增 1 行，删除 1 行，相同 2 行

philokun diff -u a.txt b.txt
# -b
# +x
```

## 标记说明

| 标记 | 含义 |
|------|------|
| `+` | 仅在 B 中出现的行（新增） |
| `-` | 仅在 A 中出现的行（删除） |
| （空格） | 两文件都有（上下文） |

## 实现说明

- 用二维 DP 求 LCS，回溯得到逐行差异序列，时间复杂度 O(n·m)。
- 大文件自动放大扫描缓冲区（最大 1MB/行），避免超长行截断。
- 末尾换行不影响比较；输出末尾给出增/删/同的汇总计数。
