# age — 年龄 / 日期差计算

计算从某日期到今天（或到指定结束日期）的年龄与精确时长。纯标准库实现。

## 用法

| 命令 | 作用 |
|------|------|
| `philokun age <出生日期>` | 计算到今天的年龄 |
| `philokun age <开始> <结束>` | 计算两个日期之间的差 |

## 示例

```bash
# 到今天
philokun age 1990-05-20
# 从 1990-05-20 到 2026-08-13：
#   36 年 2 个月 24 天
#   合计约 13234 天

# 两个日期差
philokun age 2024-01-01 2025-06-15

# 支持的日期格式：2006-01-02 / 2006/01/02 / 20060102
```

## 实现说明

- 日期解析支持 `2006-01-02`、`2006/01/02`、`20060102` 以及 RFC3339。
- 年/月/天差按日历精确计算（自动处理大小月与闰年）。
- 结束日期早于开始日期时给出报错。
